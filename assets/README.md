# Изображения профиля

- `previews/biba-vpn.png` — обложка Biba VPN с публичным аватаром [@BibaVPN_bot](https://t.me/BibaVPN_bot). Это брендовая обложка, не снимок личного кабинета. Статистика пользователей, серверов и платежей в изображение не добавлялась.
- `previews/e-echo.webp` — скриншот [эко-парка «Эхо»](https://e-echo.ru/).
- `previews/boostpaystore.webp` — скриншот [BoostPayStore](https://boostpaystore.ru/).
- `previews/nokturn.webp` — скриншот [NOKTURN](https://hippi44.github.io/lendingPage/).
- `previews/automation.svg` — схема по исходникам `automation-system`: Telegram → NestJS API → BullMQ/Redis → worker, с хранением заявок и результатов в PostgreSQL.
- `github-metrics-*.svg` — статистика из GitHub API, источник — `github-metrics.json`.

Скриншоты сделаны 14 ноября 2026 года в отдельном профиле браузера, без входа в аккаунты и отправки форм. Содержимое интерфейсов не перерисовывалось; добавлена только рамка браузера. Числа и маркетинговый текст внутри страниц относятся к содержимому сайтов, не к достижениям разработчика.
